# MyJSScripts
01. Subtitle maker - Convert text to SRT

Pormpts:
Using html and jquery, make a subtitle generator to convert lines of text into subtitle in srt format. Here are the detailed steps: codes to parse few lines of text into an array. Have a start button, on click it will start a timer. Have another button, on first click it will get the first line of text from array then apply the current time as the start time stamp, on second click it will apply the current time as the end time stamp for this line. Then next click will continue to do the same for next line of text.
